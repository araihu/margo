# PDF documents

Margo renders the compiled document as HTML, then sends it through a selected
or auto-discovered local browser engine. PDF output uses the same document
semantics as HTML.

## CLI

```sh
margo pdf guide.md \
  --output guide.pdf \
  --page-size A4 \
  --orientation portrait
```

Engine mode defaults to `auto`. Margo can discover an installed Chromium-family
executable, but it does not download one. Run `margo doctor` to inspect engine
candidates and capabilities.

## Page geometry

Page size, orientation, and each physical margin are independently configurable:

```yaml
margo:
  page:
    size: Letter
    orientation: landscape
    margins:
      top: 12
      right: 0
      bottom: 12
      left: 0
```

An explicit CLI flag overrides a document preference. A margin of `0` requests
full bleed on that edge.

## Editorial furniture

The standalone `margo pdf` command places the Margo logo and name in the header,
then adds the document title and `Generated by Margo` to the footer. PDFs from a
configured site's page action use that site's name and logo instead. This print
furniture is part of the HTML projection and does not depend on the interactive
Goshtoso site shell.

## Link policy

PDF output strips relative link targets by default while retaining visible
text. Use `--relative-links resolve --base-url URL` to resolve them against a
public base URL.
