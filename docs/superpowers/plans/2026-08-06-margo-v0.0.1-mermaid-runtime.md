# Margo Mermaid and runtime implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Embed Mermaid 11.16.1 and execute fenced diagrams through fail-closed `margo-runtime/v1` readiness with deterministic IDs, a reviewed closed SVG/CSS profile, and isolated render instances.

**Architecture:** Core compiles Mermaid source into immutable runtime tasks without claiming generated SVG. Browser runtime serializes Mermaid initialization/rendering, normalizes detached SVG IDs/references/CSS, validates against `margo-mermaid-svg/v1`, inserts accepted bytes, then participates in a monotonic readiness/report protocol.

**Tech Stack:** Go 1.26.5, Muamba v0.0.3 strict locks, embedded Mermaid ESM 11.16.1, browser DOM/XML/CSS parsers, authored JavaScript, RFC 8785/SHA-256, browser conformance fixtures.
