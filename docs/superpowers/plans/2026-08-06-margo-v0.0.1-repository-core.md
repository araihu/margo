# Margo repository and core implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the lightweight `github.com/araihu/margo` root module for immutable single-document compilation, fail-closed policy, semantic Goshtoso rendering, offline standalone HTML, and deterministic identity.

**Architecture:** `Compiler` snapshots configuration and source, produces an opaque immutable `Document` plus frozen render plan, then renders only with an equivalent compiler fingerprint. Parsing, policy, extensions, rendering, assets, and identity stay separate. Optional modules register through root interfaces; root never imports them.

**Tech Stack:** Go 1.26.5, Goldmark CommonMark/GFM/footnotes, YAML, templ, Goshtoso CodeBlock/Table, Chroma, RFC 8785 canonical JSON, embedded assets.

## Global constraints

- Roadmap file map and interface ledger are binding. Wave 0 infrastructure remains outside this plan.
- Root dependencies exclude Goshtoso Charts, PDF/browser bindings, Chromium, and CGO.
- `Source.Content`, mutable options, registry inputs, metadata, diagnostics, maps, and slices are copied or returned defensively.
- Compiler and Document are safe for concurrent operations; compile caller owns non-mutation only during `Compile`.
- `CompilerConfigFingerprint` uses `SHA-256("margo/compiler-config/v1\n" || RFC8785(preimage))`.
- `DocumentFingerprint` uses `SHA-256("margo/document/v1\n" || RFC8785(preimage))`.
- Raw HTML defaults to deny. Sanitized mode accepts only exact `margo-html-v1`; any disallowed node/attribute/URL fails before defense-in-depth sanitization.
- Unknown `goshtoso` frontmatter fields fail; generic unknown top-level fields remain host metadata.
- Presentation precedence is API/CLI, frontmatter, project, built-in. Security uses intersection, never last-writer-wins.
- `goshtosochart` without registered charts integration fails compilation; it never degrades to a code block.
- Standalone uses deterministic `ri-00000000`; embedded caller supplies or allocates a valid distinct instance in later runtime tasks.
- No batch/glob execution ships. Output mapper types reserve the post-v0.0.1 seam only.
- Public standalone HTML renders complete route-specific social metadata in initial HTML only when supplied an authority-approved `CanonicalOrigin`. Private/local output omits canonical/Open Graph/X URLs. Margo's owned preview asset is `assets/social/margo-v0.0.1.png`, exactly 1280 by 640, `image/png`, and below 1,000,000 bytes.

type RawHTMLMode string
const ( RawHTMLDeny RawHTMLMode = "deny"; RawHTMLSanitized RawHTMLMode = "sanitized" )
const ( MinOutputBytes int64 = 1; MaxOutputBytes int64 = 64 << 20 )
type Policy struct { RawHTML RawHTMLMode; OutputBytes int64 }
type EffectivePolicy struct { RawHTML RawHTMLMode; OutputBytes int64 }
func intersectPolicy(host, project Policy, declared Requirements) (EffectivePolicy, error) {
    effective := EffectivePolicy{RawHTML: mostRestrictiveHTML(host, project, declared), OutputBytes: mostRestrictiveOutput(host, project)}
    if effective.OutputBytes < MinOutputBytes || effective.OutputBytes > MaxOutputBytes { return EffectivePolicy{}, diagnostic("policy.output_bytes_invalid") }
    return effective, verifyRequirements(effective, declared)
}
