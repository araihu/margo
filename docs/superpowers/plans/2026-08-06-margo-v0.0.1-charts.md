# Margo charts module implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `github.com/araihu/margo/charts` with strict YAML/JSON `goshtosochart` fences for accessible static bar, line, pie/doughnut, and scatter SVG.

**Architecture:** Charts module registers the reserved fence through root extension API, decodes a versioned closed schema, performs semantic/resource validation, then adapts renderer-neutral values to Goshtoso Charts static components. Root remains independent and reports a missing-integration diagnostic.

**Tech Stack:** Go 1.26.5, embedded JSON Schema, strict YAML/JSON, Margo extension API, Goshtoso Charts static `bar`, `line`, `pie`, and `scatter` components.

- `AccessibleText` has one canonical field order: `Series|Category|Sample|Value`. A row with empty `Series` and empty `Sample` serializes as `Category|Value`; a row with non-empty `Series` and empty `Sample` serializes as `Series|Category|Value`; an aligned row serializes all four fields. `Category` and `Value` are required for every form, `Sample` is forbidden when `Series` is empty, and no other empty field is accepted. `EscapeAccessibleField` percent-encodes `%` as `%25`, `|` as `%7C`, UTF-8 control bytes U+0000-U+001F and U+007F as uppercase `%XX`, and rejects invalid UTF-8 with diagnostic `chart.accessibility_field_invalid`; `UnescapeAccessibleField` is the reversible test oracle. `AccessibleRenderPolicy.MaxOutputBytes` must satisfy `1 <= MaxOutputBytes <= 64<<20`; zero, negative, `math.MaxInt64`, and any larger value return `chart.output_limit_invalid` before allocation. `AccessibleText(title string, rows []AccessibleRow, policy AccessibleRenderPolicy) (string, error)` uses checked subtraction and a bounded writer, so it never creates a string beyond the accepted limit and returns `chart.output_limit` on the first byte over the limit. `WithAccessibleData` emits this exact markup in supplied row order: `<div class="margo-chart-data" data-margo-chart-data="v1"><table><caption>...</caption><tbody><tr data-margo-chart-row="0"><td data-field="series">...</td><td data-field="category">...</td><td data-field="sample">...</td><td data-field="value">...</td><td data-field="canonical">Series|Category|Sample|Value</td></tr>...</tbody></table></div>`. Original values are templ-escaped, empty fields remain empty cells, and the canonical cell contains escaped row text. `extractAccessibleRows(markup string) []string` is a test-only DOM helper that selects `table[data-margo-chart-data="v1"]` rows by numeric `data-margo-chart-row` and returns canonical cells in exact order; duplicate/missing indexes fail the helper. func TestAccessibleRowsValidateConditionalFormsAndEscapeReversibly(t *testing.T) {
```go
    require.NoError(t, validateRows([]AccessibleRow{{Category: "Desktop", Value: "40"}}))
    require.NoError(t, validateRows([]AccessibleRow{{Series: "Revenue", Category: "Development", Value: "12"}}))
    require.NoError(t, validateRows([]AccessibleRow{{Series: "Latency", Category: "p50", Sample: "12", Value: "0.2"}}))
```

```go
// extension.go imports context, io, maps, sync, and templ.
func Extension() margo.ExtensionRegistration
func extensionFactory(rc margo.RenderContext) (margo.ExtensionSession, error) {
    return chartSession{context: rc, handlers: snapshotFamilyHandlers()}, nil
}
type chartSession struct { context margo.RenderContext; handlers map[string]familyHandler }
type decodedEnvelope struct { Type string; Model any }
type familyHandler func(margo.RenderContext, any) (templ.Component, error)
var familyHandlers = map[string]familyHandler{}
func registerFamilyHandler(name string, handler familyHandler) { familyHandlers[name] = handler }
func snapshotFamilyHandlers() map[string]familyHandler { return maps.Clone(familyHandlers) }
var accessiblePolicyObserverMu sync.Mutex
var accessiblePolicyObserver func(AccessibleRenderPolicy)
func setAccessiblePolicyObserverForTest(fn func(AccessibleRenderPolicy)) (restore func()) {
    accessiblePolicyObserverMu.Lock()
    previous := accessiblePolicyObserver
    accessiblePolicyObserver = fn
    accessiblePolicyObserverMu.Unlock()
    return func() { accessiblePolicyObserverMu.Lock(); accessiblePolicyObserver = previous; accessiblePolicyObserverMu.Unlock() }
}
func observeAccessiblePolicy(policy AccessibleRenderPolicy) {
    accessiblePolicyObserverMu.Lock()
    fn := accessiblePolicyObserver
    accessiblePolicyObserverMu.Unlock()
    if fn != nil { fn(policy) }
}
func (s chartSession) Render(ctx context.Context, node margo.ExtensionNode, out io.Writer) error {
    envelope, err := decodeEnvelope(node.Payload)
    if err != nil { return err }
    handler, ok := s.handlers[envelope.Type]
    if !ok { return diagnostic("chart.type_unsupported") }
    component, err := handler(s.context, envelope.Model)
    if err != nil { return err }
    return component.Render(ctx, out)
}
func Schema(chartType string) ([]byte, error)
type envelope struct { SchemaVersion int `json:"schemaVersion" yaml:"schemaVersion"`; Type string `json:"type" yaml:"type"` }
type AccessibleRow struct { Series string; Category string; Sample string; Value string }
type AccessibleData struct { Title string; Rows []AccessibleRow }
type AccessibleRenderPolicy struct { MaxOutputBytes int64 }
func ValidateAccessibleRenderPolicy(policy AccessibleRenderPolicy) error
func AccessibleText(title string, rows []AccessibleRow, policy AccessibleRenderPolicy) (string, error)
func extractAccessibleRows(markup string) []string // test-only: exact v1 table/canonical-cell parser
func WithAccessibleData(chart templ.Component, data AccessibleData, policy AccessibleRenderPolicy) templ.Component
```

Schemas require `schemaVersion`, `type`, and route to one family schema. Bar/line require `title`, `categories`, named series with finite `values`; pie/doughnut require `title` and named finite non-negative `slices`; scatter requires `title`, `categories`, and named categorical point/value series. JSON Schema sets `additionalProperties: false` at every object. Row validation is conditional: `Category` and `Value` are always required; `Category|Value` forbids `Series` and `Sample`; `Series|Category|Value` requires `Series` and forbids `Sample`; aligned `Series|Category|Sample|Value` requires all four; `Sample` without `Series` is rejected. `ValidateAccessibleRenderPolicy` rejects any value outside `[1, 64<<20]` with `chart.output_limit_invalid`; `checkedAccessibleCapacity` performs range checks before `int` conversion and uses checked subtraction for every write. `EscapeAccessibleField` is reversible for pipe, percent, newline, CR, and every listed control byte, and rejects invalid UTF-8 with the stable diagnostic above. `AccessibleText` and `WithAccessibleData` share the exact v1 table/canonical-cell markup and policy; no canonical alternative bypasses the limit. `extensionFactory` copies the immutable root `RenderContext` into `chartSession`; `chartSession.Render` decodes one `ExtensionNode`, selects a snapshot of the handler map, passes the same context to every family handler, and writes chart plus table into the templ component. H2-H5 register typed wrappers with `registerFamilyHandler` in their own adapter files, so H1 has no family-file ownership and H6 can exercise the complete map. The wrapper validates `margo.RenderContext.EffectivePolicy.OutputBytes` before rendering, calls `observeAccessiblePolicy` for the test-only exact-policy recorder, then writes chart and table into a private buffer with capacity `MaxOutputBytes+1`, returning `chart.output_limit` before caller output on overflow. Tests set `testOutputLimit` from the root effective chart output-byte policy rather than an ambient process limit.
